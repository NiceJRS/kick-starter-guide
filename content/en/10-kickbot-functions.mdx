  ]} />
  <ImageCaption src="/images/ch10/s10_2_step1_timers.jpg" alt="KickBot Timers panel" caption="KickBot — Timers — auto-broadcast promotions at set intervals with a minimum chat-line guard" />

<FaqItem q="KickBot isn't responding to commands — what's wrong?">
First check that KickBot has Moderator status at [dashboard.kick.com/community/moderators](https://dashboard.kick.com/community/moderators). Without it, KickBot cannot send any messages in chat.
</FaqItem>

<FaqItem q="Can I set different cooldowns for different viewers?">
Yes — KickBot supports both User Cooldown (per viewer) and Global Cooldown (all viewers share). Set the global cooldown lower for popular commands like `!discord`, and user cooldown lower for gimmicks like `!roll`.
</FaqItem>
