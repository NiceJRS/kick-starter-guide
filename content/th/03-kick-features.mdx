<StepCard step={1} title="หน้าตา Creator Dashboard">
  <SubSteps items={[
    "เข้าไปที่ <a href='https://kick.com/dashboard/stream' target='_blank'>kick.com/dashboard/stream</a> — ศูนย์ควบคุมการสตรีมทั้งหมด",
    "<strong>Stream Preview</strong> — จอตรวจสัญญาณสด &nbsp;|&nbsp; <strong>Activity Feed</strong> — แจ้งเตือน Follow/Sub/Raid &nbsp;|&nbsp; <strong>Chat Dock</strong> — อ่านและพิมพ์แชท &nbsp;|&nbsp; <strong>Quick Actions</strong> — ปุ่มทางลัด"
  ]} />
  <ImageCaption src="/images/ch3/s3_1_step1_dashboard_overview.jpg" alt="หน้าตา Creator Dashboard บน KICK" caption="Creator Dashboard — 4 แผงควบคุมหลัก" />

<StepCard step={2} title="ตั้งชื่อสตรีม หมวดหมู่ และภาษา">
  <SubSteps items={[
    "กดปุ่ม <strong>Edit Stream Info</strong> (ไอคอนดินสอ) ใน Quick Actions",
    "ใส่ <strong>Title</strong>, <strong>Category</strong> (ชื่อเกมหรือ Just Chatting) และเลือก <strong>Language → Thai</strong> เพิ่ม Tag เช่น <code>Thai</code>, <code>FPS</code>, <code>VTuber</code> เพื่อให้ Algorithm ดันช่องให้คนไทยเจอ",
    "เปิดสวิตช์ <strong>18+ Mature Content</strong> หากสตรีมมีเนื้อหาไม่เหมาะสมกับเด็ก"
  ]} />
  <ImageCaption src="/images/ch3/s3_1_step2_edit_stream_info.jpg" alt="หน้าต่าง Edit Stream Info" caption="Edit Stream Info — ตั้งชื่อ หมวดหมู่ ภาษา และเรตติ้งเนื้อหา" />
</StepCard>

<StepCard step={3} title="อัปโหลด Emotes และ Subscriber Badges">
  <SubSteps items={[
    "<strong>Emotes:</strong> ไปที่ <a href='https://dashboard.kick.com/community/chat/emotes' target='_blank'>Community → Emotes</a> อัปโหลดไฟล์ PNG พื้นหลังโปร่งใส (512×512 px) ตั้งชื่อโค้ด กด Save",
    "<strong>Badges:</strong> ไปที่ <strong>Community → Badges</strong> อัปโหลดไอคอนยศตามอายุ Sub (1, 3, 6 เดือน, 1 ปี)"
  ]} />
  <ImageCaption src="/images/ch3/s3_1_step3_emotes_badges.jpg" alt="หน้าอัปโหลด Emotes และ Badges" caption="Community → Emotes — อัปโหลด Emote สำหรับ Follower และ Subscriber Badges" />
</StepCard>

<TipBox>
ตั้งค่า <strong>Language → Thai</strong> และเลือก <strong>Category</strong> ให้ตรงกับเกมที่เล่น — สองอย่างนี้ส่งผลมากที่สุดต่อการที่ Algorithm จะแสดงช่องของคุณให้คนไทยเจอ

<SectionHeading id="s3-3">3.3 Channel Points & Community</SectionHeading>

<StepCard step={6} title="เปิด Channel Points และสร้าง Custom Rewards">

    "กด <strong>+ Add Custom Reward</strong> → ตั้งชื่อรางวัล (เช่น <code>สตรีมเมอร์ดื่มน้ำ</code>) กำหนดแต้มและ Cooldown → <strong>Save</strong>"

  <ImageCaption src="/images/ch3/s3_3_step6_channel_points.jpg" alt="หน้าตั้งค่า Channel Points" caption="Community → Chat → Channel Points — สร้างรางวัลให้คนดูแลกด้วยแต้มสะสม" />
</StepCard>

<StepCard step={7} title="Polls และ Predictions">
  <SubSteps items={[
    "<strong>Poll:</strong> พิมพ์ <code>/poll [คำถาม] | [ตัวเลือก1] | [ตัวเลือก2]</code> ในแชท หรือกด <strong>Create a Poll</strong> ใน Quick Actions",
    "<strong>Prediction:</strong> กด <strong>Start Prediction</strong> ใน Quick Actions → ตั้งหัวข้อและตัวเลือก → คนดูนำแต้มมาร่วมทาย"
  ]} />
  <ImageCaption src="/images/ch3/s3_3_step7_polls_predictions.jpg" alt="หน้าจอ Poll และ Prediction" caption="Quick Actions — สร้างโพลและเกมทายผลให้คนดูมีส่วนร่วม" />
</StepCard>

<StepCard step={8} title="Raid — ส่งต่อคนดูให้สตรีมเมอร์คนอื่น">
  <SubSteps items={[
    "ก่อนจบสตรีม: พิมพ์ <code>/raid [ชื่อช่อง]</code> ในแชท (เช่น <code>/raid nicejrs</code>) หรือกด <strong>Raid Channel</strong> ใน Quick Actions",
    "ระบบนับถอยหลัง 60 วินาที → กด <strong>Raid Now</strong> เพื่อส่งผู้ชมทั้งหมดไปยังช่องเป้าหมายทันที"

**Q: VODs เก็บไว้นานแค่ไหน?**  
A: 60 วันโดยอัตโนมัติ ไม่ต้องตั้งค่า จัดการได้ที่ Studio → VODs

**Q: หาเมนู Channel Points และ Emotes ได้ที่ไหน?**  
A: Emotes → `Community → Chat → Emotes` | Channel Points → `Community → Chat → Channel Points`
