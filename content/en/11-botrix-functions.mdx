<StepCard step={1} title="BotRix — Set Up a Custom Command with Cooldown">

</TipBox>

<SectionHeading id="s11-2">2. Timers (PromptPay / TipMe Donation Link)</SectionHeading>

<StepCard step={1} title="BotRix — Auto-Broadcast Your Donation Link on a Timer">
  <SubSteps items={[
    "Go to <a href='https://botrix.live' target='_blank'>botrix.live</a> → <strong>Chatbot</strong> → <strong>Timers</strong>.",
    "Click <strong>+ Create</strong>.",
    "Set <strong>Name</strong>: <code>DonateLink</code>",
    "Set <strong>Interval</strong>: <code>20 minutes</code>.",
    "Set <strong>Lines</strong>: <code>5 lines</code> — minimum chat activity before the timer posts.",
    "Set <strong>Message</strong>: <code>Support via PromptPay (TipMe): https://tipme.in.th/yourchannel</code>",
    "Click <strong>Save</strong>."
  ]} />
  <ImageCaption src="/images/ch11/s11_2_step1_timers.jpg" alt="BotRix Timers panel — donation link timer setup" caption="BotRix — Chatbot → Timers — auto-broadcast your PromptPay/TipMe link every 20 minutes" />
</StepCard>

<TipBox>
BotRix's timer uses a Lines threshold — it only posts when at least N chat messages have occurred since the last post. This prevents the bot from spamming donation links during quiet chat periods.
</TipBox>

<SectionHeading id="s11-3">3. Subscriber-Exempt Link Protection</SectionHeading>

<StepCard step={1} title="BotRix — Enable Link Protection with Subscriber Exemption">
  <SubSteps items={[
    "Go to <a href='https://botrix.live' target='_blank'>botrix.live</a> → <strong>Modules</strong> → <strong>Moderation</strong> → <strong>Link Protection</strong>.",
    "Toggle <strong>Link Protection</strong> to ON.",
    "Under <strong>Exempted Roles</strong>, check both <strong>Subscribers</strong> and <strong>Moderators</strong>.",
    "General viewers who post links will have their messages auto-deleted.",
    "Subscribers and Moderators can post links freely — no action taken on their messages."
  ]} />
  <ImageCaption src="/images/ch11/s11_3_step1_link_protection.jpg" alt="BotRix Link Protection with Exempted Roles checked" caption="BotRix — Link Protection — Subscribers and Mods exempted; general viewer links auto-purged" />
</StepCard>

<TipBox>
This is BotRix's standout feature — KICK's native Block Links cannot distinguish between viewer types. BotRix lets Subscribers post links freely while blocking everyone else, which rewards your paying viewers.
</TipBox>

<StepCard step={1} title="BotRix — Limit Emote Spam Per Message">

    "Set <strong>Limit</strong>: <code>5</code> — maximum number of emotes allowed per message.",
    "Set <strong>Action</strong>: <code>Delete Message & Timeout 10s</code>.",
    "Any message with more than 5 emotes will be deleted and the sender timed out for 10 seconds."
  ]} />
  <ImageCaption src="/images/ch11/s11_4_step1_emote_limit.jpg" alt="BotRix Emote Protection settings panel" caption="BotRix — Emote Protection — max 5 emotes per message, auto-delete + 10s timeout" />
</StepCard>

<TipBox>
Adjust the Limit to match your community norms. A limit of 5 works well for most chats; increase it to 10 if your audience loves emote spam during hype moments.
</TipBox>

<SectionHeading id="s11-6">6. Gimmick Commands (!roll, !rps)</SectionHeading>

<StepCard step={1} title="BotRix — Create Interactive Gimmick Commands">
  <SubSteps items={[
    "Go to <a href='https://botrix.live' target='_blank'>botrix.live</a> → <strong>Chatbot</strong> → <strong>Commands</strong> → click <strong>+ Add Command</strong>.",
    "<strong>Create !roll:</strong>",
    "Set <strong>Command</strong>: <code>!roll</code>",
    "Set <strong>Response</strong>: <code>@$(user) rolled: $(rand.1-100) pts! 🎲</code>",
    "Set <strong>Cooldown</strong>: <code>30s</code>.",
    "Click <strong>Save</strong>.",
    "<strong>Create !rps (Rock Paper Scissors):</strong>",
    "Click <strong>+ Add Command</strong> again.",
    "Set <strong>Command</strong>: <code>!rps</code>",
    "Set <strong>Response</strong>: <code>@$(user) played: $(rand.pick Rock,Paper,Scissors) ✂️🔨📄</code>",
    "Set <strong>Cooldown</strong>: <code>10s</code>.",
    "Click <strong>Save</strong>."
  ]} />
  <ImageCaption src="/images/ch11/s11_6_step1_gimmick_commands.jpg" alt="BotRix !roll command with $(rand..) variable" caption="BotRix — !roll using $(rand.1-100) — note BotRix uses $(rand) not $(random) like KickBot" />
</StepCard>

<TipBox>
BotRix uses <code>$(rand.1-100)</code> and <code>$(rand.pick ...)</code> for random values. KickBot uses <code>$(random.1-100)</code> — the syntax differs, so keep this in mind if you run both bots at once.
</TipBox>

<FaqItem q="BotRix alerts aren't showing in OBS — what's wrong?">
Check two things: (1) BotRix must have Moderator status at [dashboard.kick.com/community/moderators](https://dashboard.kick.com/community/moderators), and (2) the Alerts Browser source must be the topmost layer in your OBS scene so it's not hidden behind other sources.
</FaqItem>

<FaqItem q="Can viewers skip songs in the !sr queue?">
BotRix's !sr queue is managed by the streamer — you control playback. The bot queues requests from viewers, but only you can skip or remove songs from the list.
</FaqItem>
