**Q: Moderator สามารถเปิด Prediction หรือแก้ไขรายละเอียดสตรีมได้ไหม?**  
A: ได้ Mod สามารถรัน `/prediction`, เปิด `/poll`, ใช้คำสั่ง `/raid` และอัปเดตชื่อสตรีม/หมวดหมู่ผ่าน Mod View Dashboard

**Q: จะรู้ได้อย่างไรว่า Mod คนไหนแบนหรือ Timeout คนดู?**  
A: ตรวจสอบได้ที่ Mod Actions Log ใน Mod View ที่ `kick.com/moderator/[username]` — ทุกการกระทำจะถูกบันทึกพร้อมชื่อ Mod และ timestamp

**Q: จะ Unban คนที่ถูก Ban ไปแล้วได้อย่างไร?**  
A: พิมพ์ `/unban [username]` ในแชทสด หรือไปที่ Creator Dashboard → Moderation → Banned users แล้วลบรายชื่อออก
