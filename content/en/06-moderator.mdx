**Q: Can Moderators initiate Predictions or edit stream details?**  
A: Yes. Mods can run `/prediction`, start `/poll`, execute `/raid`, and update stream title/category via the Mod View Dashboard.

**Q: How do I find out which Moderator banned or timed out a viewer?**  
A: Check the Mod Actions Log inside Mod View at `kick.com/moderator/[username]` — every action is logged with the mod's name and timestamp.

**Q: How do I unban someone who was previously banned?**  
A: Type `/unban [username]` in live chat, or go to Creator Dashboard → Moderation → Banned users and remove them from the list.
