<FaqItem q="Moderator สามารถเปิด Prediction หรือแก้ไขรายละเอียดสตรีมได้ไหม?">
ได้ Mod สามารถรัน `/prediction`, เปิด `/poll`, ใช้คำสั่ง `/raid` และอัปเดตชื่อสตรีม/หมวดหมู่ผ่าน Mod View Dashboard
</FaqItem>

<FaqItem q="จะรู้ได้อย่างไรว่า Mod คนไหนแบนหรือ Timeout คนดู?">
ตรวจสอบได้ที่ Mod Actions Log ใน Mod View ที่ `kick.com/moderator/[username]` — ทุกการกระทำจะถูกบันทึกพร้อมชื่อ Mod และ timestamp
</FaqItem>

<FaqItem q="จะ Unban คนที่ถูก Ban ไปแล้วได้อย่างไร?">
พิมพ์ `/unban [username]` ในแชทสด หรือไปที่ Creator Dashboard → Moderation → Banned users แล้วลบรายชื่อออก
</FaqItem>
