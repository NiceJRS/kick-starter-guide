<SectionHeading id="s5-1">5.1 Chatbot Selection</SectionHeading>

<StepCard step={1} title="เปรียบเทียบ KickBot vs BotRix">
  <SubSteps items={[
    "บอทยอดนิยมที่ออกแบบมาสำหรับ KICK โดยเฉพาะมี 2 ตัวหลัก ได้แก่ <strong>KickBot</strong> และ <strong>BotRix</strong> — แต่ละตัวเด่นคนละด้าน",
    "<strong>KickBot (<a href='https://kickbot.com' target='_blank'>kickbot.com</a>):</strong> เหมาะกับสายเอนเตอร์เทนที่ต้องการ AI เสียงอ่านแชทสด (TTS), คำสั่งตัดคลิป VOD อัตโนมัติ (<code>!clip</code>) และกิมมิกสุ่มตัวเลขในแชท",
    "<strong>BotRix (<a href='https://botrix.live' target='_blank'>botrix.live</a>):</strong> เหมาะกับคนที่ต้องการกรอบแจ้งเตือน Follow/Sub บน OBS Studio, ระบบคัดกรองลิงก์แยกยศ Subscriber, ตั้งเวลาโพสต์ลิงก์โดเนทพร้อมเพย์ (TipMe) และกรอบซิงก์ชื่อเพลง Now Playing"
  ]} />
  <ImageCaption src="/images/ch5/s5_1_step1_compare_bots.jpg" alt="หน้าหลัก KickBot และ BotRix เปรียบเทียบกัน" caption="KickBot vs BotRix — เลือกตามฟีเจอร์ที่ต้องการใช้มากที่สุด" />
</StepCard>

| ฟังก์ชั่น | KickBot (kickbot.com) | BotRix (botrix.live) |
| :--- | :--- | :--- |
| **จุดเด่นหลัก** | AI Text-to-Speech & VOD Clipping | Alerts Overlay & Moderation |
| **Custom Commands + Cooldown** | ✅ ตั้งค่าง่าย + ตั้ง Cooldown กันสแปมได้ | ✅ ตั้งค่าง่าย + ตั้ง Cooldown กันสแปมได้ |
| **Timers (ส่งข้อความประกาศ)** | ✅ ตั้งเวลาเว้นระยะ + รองรับเสียง AI อ่าน | ✅ ตั้งเวลาเว้นระยะ + กำหนด Chat Lines ได้ |
| **Link Protection (คัดกรองลิงก์)** | ✅ มีระบบ Spam & Link Protection | ✅ **เด่นมาก** ปลดล็อกสิทธิ์แปะลิงก์เฉพาะ Sub/Mod ได้ |
| **Emote Limit Protection** | ✅ บล็อกการสแปมข้อความซ้ำ | ✅ **เด่นมาก** กำหนดจำนวน Emote สูงสุดต่อข้อความได้ |
| **ฟีเจอร์เด่น** | ✅ **AI TTS** อ่านแชทสดธรรมชาติ 150+ เสียง | ✅ **Stream Alerts Overlay** แจ้งเตือน Follow/Sub บน OBS |
| **Gimmick Commands (!roll, !rps)** | ✅ ใช้ Variable `$(random.1-100)` | ✅ ใช้ Variable `$(rand.1-100)` |
| **Live Chat Overlay Widget** | ✅ ปรับแต่งธีม/พื้นหลังโปร่งใสได้ | ✅ ปรับแต่งสไตล์ธีมแชทลอยได้ |
| **Music Overlay & Song Request (!sr)** | ❌ ต้องใช้แอปเล่นวิดีโอภายนอก | ✅ **เด่นมาก** ระบบ `!sr` ขอเพลง + กรอบ Now Playing บน OBS |

<TipBox>
คุณสามารถใช้งานทั้งสองบอทพร้อมกันได้ — ใช้ KickBot สำหรับ AI TTS + !clip และใช้ BotRix สำหรับ OBS Alerts + คัดกรองลิงก์แยกยศ + กรอบเพลง
</TipBox>
